Tin tuyển dụng

Soạn và xuất bản tin tuyển dụng bằng tiếng Việt. Nội dung tin không thay đổi khi chuyển ngôn ngữ giao diện.

Liên kết đăng tuyển

Tạo liên kết landing page chung và đường dẫn ứng tuyển trực tiếp cho từng vị trí.

Landing page công khai

URL GitHub Pages hoặc domain sau khi triển khai

Cách chia sẻ

Sao chép liên kết của một vị trí để mở thẳng form ứng tuyển. Chỉ tin đang hoạt động mới được hiển thị công khai.

Cài đặt hệ thống

Quản lý bảo mật tài khoản và liên kết giữa landing page, Worker và Google Sheets.

Đổi mật khẩu quản trị

Hãy dùng mật khẩu riêng có tối thiểu 12 ký tự. Mật khẩu được xác thực phía máy chủ.

Kết nối hệ thống

Giao diện Admin chạy trên GitHub Pages. Cloudflare Worker xử lý API bảo mật cho Google Sheets và Drive.

Mail Server hiện có

Thông tin kết nối được cấu hình trong Cloudflare Worker Secrets; không nhập khóa mail trên trang Admin.
