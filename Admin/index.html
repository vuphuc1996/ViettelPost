Tin tuyển dụng

Soạn và xuất bản tin song ngữ. Các tin đang hoạt động sẽ xuất hiện trên landing page.

Liên kết đăng tuyển

Tạo liên kết landing page chung và đường dẫn ứng tuyển trực tiếp cho từng vị trí.

Landing page công khai

URL GitHub Pages hoặc domain sau khi triển khai

Cách chia sẻ

Sao chép liên kết của một vị trí để mở thẳng form ứng tuyển. Chỉ tin đang hoạt động mới được hiển thị công khai.

Cài đặt hệ thống

Quản lý bảo mật tài khoản và cấu hình liên kết giữa landing page và Google Sheets.

Đổi mật khẩu quản trị

Hãy dùng mật khẩu riêng có tối thiểu 10 ký tự. Mật khẩu được xác thực phía máy chủ.

Kết nối hệ thống

Giao diện Admin chạy trên GitHub Pages. Google Apps Script cung cấp API bảo mật để đọc/ghi Google Sheets.

BackendGoogle Apps Script
DatabaseGoogle Sheets
Tài khoảnAdmin
Landing page—
Triển khai GAS dưới dạng API Web App (Execute as me). Chỉ origin GitHub Pages đã cho phép mới nhận được phản hồi; thao tác quản trị vẫn cần phiên đăng nhập hợp lệ.

Cấu hình máy chủ mail (phát triển sau)

Thông số được lưu trong Script Properties; mật khẩu không ghi vào Google Sheets và không hiển thị lại.

ĐANG KHÓA GỬI MAIL
Tạm thời chưa gửi email và chưa kiểm tra kết nối trong phiên bản này. Apps Script không mở được kết nối SMTP TCP trực tiếp; cần tích hợp SMTP relay/API trước khi bật. Lưu cấu hình sẽ không gửi email.
